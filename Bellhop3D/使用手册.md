# BELLHOP3D 使用手册

本手册对应本目录 `bellhop3d.exe` 和 `run_bellhop3d.m`。命令在 MATLAB 中执行。完整环境准备和数据读取见公共目录《使用手册_从零复现》。

## 1. 它直接计算什么

```text
demo.env → bellhop3d.exe → demo.shd + demo.prt
项目封装读取三维复声压 → field3d.mat + 图像
```

本手册使用相干声场模式，不需要 KRAKEN 的 `.mod`，也不需要 FIELD。BELLHOP3D 是声线/波束追踪模型，可以启用全三维传播；它不是完整三维波动方程求解器。

本例平坦、水平不变，输出应接近轴对称。全三维模式在这样的环境中不会凭空产生方位差异。若研究真正的水平折射，需要进一步提供相应三维环境，当前简单配置没有实现那部分输入。

## 2. 使用当前封装

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
cd(fullfile(projectRoot,'Bellhop3D'));
result = run_bellhop3d();
disp(result.outputDir);
size(result.pressure) % 39 501 36
openfig(fullfile(result.outputDir,'field_3d.fig'),'new','visible');
```

默认 500 Hz，俯仰角 −80～80°、1601 个发射角，水平发射角请求 145 个端点样本覆盖 0～360°，积分步长 10 m。程序去掉 360° 的重复方向后，实际追踪 144 个水平发射方向。

## 3. 原生程序小练习

已提供 `examples/demo.env`。它使用 20 个接收深度、11 个距离、12 个方位；波束数降低为 401×36 个实际发射方向，适合快速学习输入格式。**它不是经过同等精度验证的默认生产设置。**

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
modelDir = fullfile(projectRoot,'Bellhop3D');
outDir = fullfile(modelDir,'results', ...
    ['manual_' char(datetime('now','Format','yyyyMMdd_HHmmss_SSS'))]);
mkdir(outDir);
copyfile(fullfile(modelDir,'examples','demo.env'),outDir);
oldDir = pwd;
cd(outDir);
try
    [status,logText] = system(sprintf('"%s" demo',fullfile(modelDir,'bellhop3d.exe')));
    disp(logText);
    assert(status==0 && isfile('demo.shd'),'BELLHOP3D failed; inspect demo.prt');
    prt = fileread('demo.prt');
    assert(contains(prt,'3D calculation'));
    assert(~contains(prt,'N x 2D calculation'));
catch ME
    cd(oldDir);
    rethrow(ME);
end
cd(oldDir);
disp(outDir);
```

核心原生命令为 `bellhop3d.exe demo`。得到 `demo.shd` 后按总手册第 10 节绘图，读取器返回的维度为 **[12,1,20,11]**。

## 4. 看懂 demo.env 的结构

前半段描述与其他模型相同的物理水层，后半段专门描述三维声源、接收点和发射波束。

| 顺序 | 示例 | 含义 |
|---|---|---|
| 标题、频率、媒质数 | 标题；500；1 | 单频、一个有限流体水层 |
| 插值/海面/衰减单位 | `'CVW'` | 声速线性、压力释放海面、dB/波长 |
| 水层与海底 | 200 m；1500/1600 m/s | 与其他小示例相同 |
| 源 x 数量和值 | `1`、`0 /` | 水平坐标 km |
| 源 y 数量和值 | `1`、`0 /` | 水平坐标 km |
| 源深数量和值 | `1`、`25 /` | 深度 m |
| 接收深度数量和值 | `20`、`5 195 /` | m |
| 接收距离数量和值 | `11`、`0.5 1.5 /` | 相对于声源的水平距离 km |
| 接收方位数量和值 | `12`、`0 330 /` | 每隔 30° 一个接收方位 |
| 运行方式 | `'CG RR3'` | 相干、几何帽形波束、点源、规则接收网格、全三维 |
| 俯仰发射数量和范围 | `401`、`-80 80 /` | 发射角间隔 0.4° |
| 水平发射数量和范围 | `37`、`0 360 /` | 请求包含端点；去重后 36 方向 |
| 步长和计算框 | `10 1.65 1.65 201` | 步长 m；水平框 x/y 为 km；垂直框 z 为 m |

与 KRAKEN 不同，这里没有 `CLOW CHIGH` 与模态精度控制 `RMAX` 段。不能将 KRAKEN 文件直接交给 BELLHOP3D。水层头部保留的网格数也不能当作 BELLHOP 声线积分精度，波束数量和步长才是本例要独立检查的数值设置。

## 5. `'CG RR3'`：空格也是格式的一部分

```text
字符位置：1 2 3 4 5 6
字符内容：C G _ R R 3
```

`_` 只是上面为显示空格而使用的标记；文件中必须是实际空格。

| 位置 | 当前值 | 含义 |
|---|---|---|
| 1 | C | 相干声压场，保留干涉与相位 |
| 2 | G | 几何帽形波束 |
| 3 | 空格 | 本例使用默认设置，保留该位置 |
| 4 | R | 点源/柱面坐标相关设置 |
| 5 | R | 规则接收网格 |
| 6 | 3 | 全三维传播；2 对应 Nx2D |

格式已按本机 `Bellhop/ReadEnvironmentBell.f90` 核对。初次复现请保持字符串不变，并检查 `.prt` 中的 `3D calculation`。

原生程序还提供声线、到达结构、非相干等运行方式，其输出不同。**当前 `run_3d_field` 封装只支持相干全三维几何帽形/高斯波束的声场读取，不支持把选项改成声线模式后仍按相同 MAT 流程处理。**

## 6. 接收角、发射角与步长必须分清

- `cfg.bearingDeg`：想在哪些方向获得输出。
- `cfg.bellhop.nBeta`：实际发射多少水平波束样本；当前生成器固定覆盖 0～360°。
- `cfg.bellhop.nAlpha`：俯仰方向的发射样本数。
- `cfg.bellhop.stepM`：追踪声线时的积分步长。
- `cfg.rangeM/depthM`：保存声场的接收采样位置，不能代替积分步长和波束收敛控制。

只增加接收方位数，不能自动提高波束追踪精度；只增加波束数，也不会使保存的接收网格变密。提升频率或延长距离后，应重新检查数值稳定性。

## 7. 单独验证波束设置

以下代码按同一接收网格计算两次，成本高于普通运行：

```matlab
cd(projectRoot); addpath(projectRoot);
cfg = field3d_config();
cfg.makePlots = false;
cfg.rangeM = 500:250:3000;
cfg.depthM = 10:20:190;
cfg.bearingDeg = 0:30:330;
A = run_3d_field('Bellhop3D',cfg);

cfg.bellhop.nAlpha = 2*(cfg.bellhop.nAlpha-1)+1;
cfg.bellhop.nBeta = 2*(cfg.bellhop.nBeta-1)+1;
cfg.bellhop.stepM = cfg.bellhop.stepM/2;
B = run_3d_field('Bellhop3D',cfg);
pa = double(A.pressure(:)); pb = double(B.pressure(:));
relativeChange = norm(pa-pb)/norm(pb)
```

当前默认环境在相同验证网格上的已有结果约为 0.0678%。如果变化明显增大，分别检查俯仰角、水平角、积分步长及发射角范围。不要只看一张平滑的 TL 图来判断收敛。

这个验证只比较离散化变化，不证明波束模型与完整波动问题一致。声线近似没有对所有环境通用的最低频率；500 Hz 只是当前算例选择。近源、临界角、阴影区、复杂边界散射等问题仍需模型适用性判断。

## 8. 结果解释和限制

默认保存的 `pressure` 顺序为 [深度,水平距离,方位]；原生 SHD 读取器的顺序不同。当前同一距离、深度的不同方位声场应基本相同。

与 KRAKENC/FIELD 比较时，已有结果发现接近 180° 的整体相位偏移。先比较 TL、相关度和相位参考，再判断误差来源，不要自动共轭数据。详细指标见公共目录 `RESULTS.md`。

冰层几何并不等于完整弹性冰层物理；要把本例改成冰下场景，需要另外设计反射或弹性边界等效方案并验证。三维输入形式与理论可进一步查阅 [BELLHOP3D 作者手册](https://avc-adelaide.github.io/aubellhop/media/Bellhop3D%20User%20Guide%202016_7_25.pdf)；本手册可运行格式以本机配套源码和示例为准。
