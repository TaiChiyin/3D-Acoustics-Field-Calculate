# KRAKEN 使用手册

本手册对应本目录中的 `kraken.exe`、`field.exe` 和 `run_kraken_3d.m`。先读公共目录的《使用手册_从零复现》，再做这里的独立练习。命令均在 MATLAB 中执行。

## 1. 计算流程与适用范围

```text
demo.env → kraken.exe → demo.mod
demo.mod + demo.flp → field.exe → demo.shd
本项目封装读取声场 → 在水平不变条件下扩展方位 → field3d.mat + 图像
```

KRAKEN 首先求解简正波，并不直接完成本项目所需的三维数组。FIELD 根据模态、声源与接收位置合成相干声压。当前环境的轴对称性允许写成：

`p(x,y,z) = p(r,z)`，其中 `r=sqrt((x-xs)^2+(y-ys)^2)`。

因此增加方位维度并不引入水平折射。将来若改变不同方位的海底地形或水中声速，不能继续无条件复制同一剖面。

## 2. 推荐：使用已写好的入口

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
cd(fullfile(projectRoot,'Kraken'));
result = run_kraken_3d();

```

修改配置时，从公共目录调用更清楚：

```matlab
cd(projectRoot); addpath(projectRoot);
cfg = field3d_config();
cfg.sourceXYZM = [0 0 50];
result = run_3d_field('Kraken',cfg);
```

入口自动写 `case.env`、调用 KRAKEN、写 `case.flp`、调用 FIELD、读取输出、扩展方位并保存数据。

## 3. 练习原生程序：自己运行 KRAKEN 和 FIELD

本目录 `examples/demo.env` 与 `examples/demo.flp` 已提供完整输入。它们保留 500 Hz 浅海环境，但接收网格较小，仅用于理解工具流程，不能拿它们的数组尺寸与默认三维结果直接比较。

运行以下整段代码；它会创建新目录，保留原示例不动：

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
modelDir = fullfile(projectRoot,'Kraken');
outDir = fullfile(modelDir,'results', ...
    ['manual_' char(datetime('now','Format','yyyyMMdd_HHmmss_SSS'))]);
mkdir(outDir);
copyfile(fullfile(modelDir,'examples','demo.env'),outDir);
copyfile(fullfile(modelDir,'examples','demo.flp'),outDir);
oldDir = pwd;
cd(outDir);
try
    [statusMode,logMode] = system(sprintf('"%s" demo',fullfile(modelDir,'kraken.exe')));
    disp(logMode);
    assert(statusMode==0 && isfile('demo.mod'),'KRAKEN failed; inspect demo.prt');
    [statusField,logField] = system(sprintf('"%s" demo',fullfile(modelDir,'field.exe')));
    disp(logField);
    assert(statusField==0 && isfile('demo.shd'),'FIELD failed; inspect field.prt');
catch ME
    cd(oldDir);
    rethrow(ME);
end
cd(oldDir);
disp(outDir);
```

核心原生命令相当于：`kraken.exe demo`，然后 `field.exe demo`。不要写成 `kraken.exe demo.env`。MATLAB 代码用完整 EXE 路径，避免依赖系统 PATH。

得到 `demo.shd` 后，按总手册第 10 节读取，维度应为 **[1,1,20,11]**。手工流程没有自动扩展方位、生成 MAT 或 PNG。

## 4. 看懂 demo.env

打开 `examples/demo.env`，按顺序阅读：

| 输入段 | 示例 | 含义 |
|---|---|---|
| 标题 | `'KRAKEN manual shallow-water example'` | 文本标签 |
| 频率 | `500` | Hz |
| 有限介质层数 | `1` | 水层；上下半空间不计入此数量 |
| 顶部/插值/衰减选项 | `'CVW'` | C：声速线性插值；V：压力释放顶部；W：dB/波长 |
| 初始网格、粗糙度、层底 | `2000 0 200` | 模态求解初始网格，平滑界面，层底 200 m |
| 水层顶部属性 | `0 1500 0 1 0 0 /` | 深度、纵波速度、横波速度、密度、纵/横波衰减 |
| 水层底部属性 | `200 1500 /` | 到 200 m 仍为 1500 m/s；其余属性沿用 |
| 底部类型 | `'A' 0` | 半空间边界、界面粗糙度 0 |
| 海底属性 | `200 1600 0 1.8 0.2 0 /` | 这里横波速度为 0，因此是流体海底 |
| 模态相速度搜索界限 | `0 20000` | m/s，不是两个介质的实际声速 |
| RMAX | `1.5` | km，服务于模态数值精度控制；不代替 FLP 接收距离设置 |
| 声源深度 | 数量 `1`，值 `25 /` | m |
| 模态输出深度 | 数量 `41`，端点 `0 200 /` | 工具箱补为 0:5:200 m，用于后续场合成 |

`NMESH` 与接收深度点数不是一回事。`modeMaxPhaseSpeedMps=20000` 也不是把水中声速改成 20000 m/s。第一次练习保留它，之后若改变搜索范围，应检查模态是否遗漏及声场是否稳定。

## 5. 看懂 demo.flp

| 输入段 | 本示例 | 含义 |
|---|---|---|
| FIELD 选项 | `'RA C'` | 第 1 位 R：点源；第 2 位 A：绝热选项；第 3 位空格：全向；第 4 位 C：相干叠加 |
| 模态使用上限 | `9999` | 使用最多 9999 个可用模态，不会额外创造模态 |
| 剖面数量、位置 | `1`、`0 /` | 一个水平不变剖面；此例没有跨剖面绝热近似问题 |
| 接收距离 | `11`、`0.5 1.5 /` | 11 个等距水平距离，单位 km |
| 声源深度 | `1`、`25 /` | 与模态计算保持一致 |
| 接收深度 | `20`、`5 195 /` | 5:10:195 m |
| 阵元距离偏移 | 数量 `20`，20 个 `0` | 无阵列倾斜偏移，数量与接收深度数一致 |

**保留 `'RA C'` 中的空格。** 改成 `'RAC'` 会改变字符位置，不是同一个设置。虽然在线旧版 FIELD 文档更简短，本手册按本机 `KrakenField/field.f90` 的四字符规则说明。

## 6. 参数修改与运行顺序

- 改水层/海底/频率：重新运行 KRAKEN 和 FIELD。
- 只改 FIELD 的接收距离：可复用对应同一环境和频率的 `.mod`，重新运行 FIELD；仍需确认原模态精度适合新的最远距离。
- 改声源/接收深度：最稳妥是同步修改 `.env` 和 `.flp`，重新计算；避免在旧的稀疏模态深度输出上误用插值。
- 修改封装配置：重新运行入口即可，程序会自动重新生成输入。不要修改旧结果中的 `case.env`，再期望入口读取这个改动；入口的参数来源是 cfg。

## 7. 必须理解的边界

KRAKEN 并非完全不能描述衰减，但其部分损耗处理采用扰动近似；对于弹性介质材料衰减，官方说明要求使用 KRAKENC。不要把当前流体浅海示例直接当作弹性冰层计算模板。[KRAKEN/KRAKENC 官方说明](https://oalib-acoustics.org/website_resources/AcousticsToolbox/manual/node47.html)

本项目默认复声压网格为离散采样，不能直接用于任意位置的精确相位插值。输出数据归一化、坐标顺序、整体相位比较和常见报错见总手册。
