# KRAKENC 使用手册

本手册对应 `krakenc.exe`、`field.exe` 和 `run_krakenc_3d.m`。命令均在 MATLAB 命令窗口执行。通用准备、数据读取和复现检查见公共目录《使用手册_从零复现》。

## 1. KRAKENC 与 KRAKEN 有什么区别

两者都采用简正波方法，都先输出 `.mod`，然后经 FIELD 得到声场。KRAKENC 使用复数算术，在复数域处理相关损耗机制；KRAKEN 对部分损耗采用扰动处理。对于需要考虑弹性介质材料衰减的问题，应使用支持该处理的 KRAKENC。**C 不是相干的缩写，KRAKEN 也能输出相干场。** [官方模型说明](https://oalib-acoustics.org/website_resources/AcousticsToolbox/manual/node47.html)

不能据此认定 KRAKENC 在任何问题上都自动正确；模态搜索、边界、网格、收敛仍需要检查。也不要套用固定的速度倍率：耗时取决于环境和实现。

当前封装采用**一个常声速流体水层 + 流体海底半空间**，不直接支持通过配置加入弹性冰层。KRAKENC 原生工具有更广泛能力，但使用那些能力需要重新编写并验证环境输入。

## 2. 一键运行

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
cd(fullfile(projectRoot,'Krakenc'));
result = run_krakenc_3d();
disp(result.outputDir);
size(result.pressure) % 39 501 36
openfig(fullfile(result.outputDir,'field_3d.fig'),'new','visible');
```

修改频率后单独计算：

```matlab
cd(projectRoot); addpath(projectRoot);
cfg = field3d_config();
cfg.frequencyHz = 300;
result = run_3d_field('Krakenc',cfg);
```

输出仍存入 `Krakenc/results/新目录/`。三维方位扩展依据水平不变环境的对称性，不是一般三维模态传播求解。

## 3. 独立运行原生程序

已提供 `examples/demo.env` 和 `examples/demo.flp`。两份文件的物理环境与 KRAKEN 练习相同，这样才能比较两种求解器。

```matlab
projectRoot = 'D:/project/matlab/MFP/project/3D_Acoutics_Field_Calculate';
modelDir = fullfile(projectRoot,'Krakenc');
outDir = fullfile(modelDir,'results', ...
    ['manual_' char(datetime('now','Format','yyyyMMdd_HHmmss_SSS'))]);
mkdir(outDir);
copyfile(fullfile(modelDir,'examples','demo.env'),outDir);
copyfile(fullfile(modelDir,'examples','demo.flp'),outDir);
oldDir = pwd;
cd(outDir);
try
    [statusMode,logMode] = system(sprintf('"%s" demo',fullfile(modelDir,'krakenc.exe')));
    disp(logMode);
    assert(statusMode==0 && isfile('demo.mod'),'KRAKENC failed; inspect demo.prt');
    [statusField,logField] = system(sprintf('"%s" demo',fullfile(modelDir,'field.exe')));
    disp(logField);
    assert(statusField==0 && isfile('demo.shd'),'FIELD failed; inspect field.prt');
catch ME
    cd(oldDir);
    rethrow(ME);
end
cd(oldDir);
disp(outDir);
```

核心次序为 `krakenc.exe demo` → `field.exe demo`。得到 `.mod` 只是第一步，必须执行 FIELD 才能得到此流程中的 `.shd`。

按总手册第 10 节加载 `demo.shd`，应得到 `[方位,源深,接收深度,距离]=[1,1,20,11]`。原生练习不自动扩展方位或生成三维 MAT。

## 4. 本例输入参数速查

本流体浅海例中，KRAKENC 与 KRAKEN 使用兼容的环境/场参数格式，主要区别是调用的求解器。

| 文件内容 | 示例 | 含义 |
|---|---|---|
| `.env` 频率 | `500` | Hz |
| `.env` 媒质数 | `1` | 有限水层数，不含半空间 |
| `.env` 选项 | `'CVW'` | 声速线性插值、压力释放海面、dB/波长 |
| 水层 | 0–200 m；1500 m/s；1.0 g/cm³ | 横波速度 0，无水体吸收 |
| 海底 | 1600 m/s；1.8 g/cm³；0.2 dB/波长 | 横波速度 0，流体半空间 |
| 初始模态网格 | `2000` | 不是模态数，也不是最终接收深度数 |
| 相速度范围 | `0 20000` | 模态搜索设置，不是水体物理声速范围 |
| RMAX | `1.5` | km，用于模态数值精度设置 |
| 源深 | `25` | m |
| 模态输出深度 | `41` 点、`0 200 /` | 0:5:200 m |
| `.flp` 选项 | `'RA C'` | 点源、单剖面下的绝热选项、全向、相干 |
| `.flp` 距离 | 11 点，0.5–1.5 km | 等间距 |
| `.flp` 深度 | 20 点，5–195 m | 等间距，偏移向量为 20 个零 |

逐段解释与 `Kraken/使用手册.md` 第 4–5 节相同。注意保留字符串内空格、两个文件同基名、水平距离 km 与深度 m 的差别。

## 5. 如何比较 KRAKEN 和 KRAKENC

回到公共目录，用同一个 cfg 运行：

```matlab
cd(projectRoot); addpath(projectRoot);
cfg = field3d_config();
A = run_3d_field('Kraken',cfg);
B = run_3d_field('Krakenc',cfg);
pa = double(A.pressure(:,:,1));
pb = double(B.pressure(:,:,1));
relativeError = norm(pa(:)-pb(:))/norm(pa(:))
coherence = abs(pa(:)'*pb(:))^2 / ...
    (sum(abs(pa(:)).^2)*sum(abs(pb(:)).^2))
```

已有默认正式结果的相关度约为 0.99536，TL 绝对差中位数约 0.169 dB。数字仅描述该基准；不同频率、底质、距离不能直接套用。

比较时先核对频率、水深、声速、密度、衰减单位、源深、接收坐标和模态搜索范围。**不要同时换模型和环境，再把所有差异都归因于模型。**

## 6. 建议练习与边界

建议先复现 0.2 dB/波长的原海底损耗，再把 cfg 中 `bottomAttenuationDbPerWavelength` 改成 0.1，使用两个模型重新计算，观察距离增大后的幅度变化。每次保存配置，不要只保存图。

不要通过对波数取实部或给声压取绝对值来“修复”复数输出；这样会删除损耗或相位信息。若要研究冰层弹性损耗，先建立独立的弹性环境并验证，不在这个流体配置上直接更改一个密度数值冒充冰层。

原生程序报错时看 `demo.prt`；FIELD 报错看 `field.prt`。不同来源的 `.mod` 和 `field.exe` 版本可能不兼容，本项目已配好同版本程序。
